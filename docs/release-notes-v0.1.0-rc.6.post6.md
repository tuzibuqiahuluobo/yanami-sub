# Yanami Sub 0.1.0 RC6.6

RC6.6 修复应用内检查更新在 GitHub 发布列表遗漏附件时跳过新版的问题。
内部版本为 `0.1.0-rc.6.post6`；字幕处理核心仍固定为
[FineSub v0.5.1](https://github.com/caca2331/finesub/tree/v0.5.1)。

## 本版更新

- 更新检查在发布列表的附件为空时，向 GitHub 查询该发布的附件列表，再按原有规则
  查找签名的在线更新清单。RC6.5 的发布列表曾显示 0 个附件，而它的独立附件接口
  已有全部 8 个文件，这会让旧版客户端误以为没有新版。
- 不改变更新清单的 Ed25519 签名、版本匹配和下载文件 SHA-256 校验；该回退仅用于
  发现附件，不放宽信任规则。
- 后续版本仍会同时发布完整安装器、完整更新包与签名的在线更新清单。

## 安装与更新

- RC5 至 RC6.5：发布后实测，GitHub 的发布列表仍遗漏 RC6.6 附件，旧版客户端暂时
  无法在应用内发现此版。请从本 Release 下载 Setup 覆盖安装一次；RC6.6 客户端已可
  自行查询独立附件接口，后续版本不再依赖发布列表内嵌的附件。
- RC4 或旧版 FineSub Desktop：运行
  `Yanami-Sub-0.1.0-rc.6.post6-Setup.exe` 覆盖安装。
- 新安装：下载 Setup 和对应 `.sha256` 文件，核对一致后运行。

安装包不做付费 Authenticode 证书签名；在线更新清单仍由项目密钥签名，下载包仍受
SHA-256 完整性校验。
