# Yanami Sub 0.3.1 RC1.2

内部版本 `0.3.1-rc.1.post2`。与正式版 0.3.0.post2 使用相同的知识库字幕定位、错误引导与圆角菜单修复，核心仍固定为 FineSub v0.7.0。

详细内容与验证边界见 [0.3.0.post2 修复说明](release-notes-v0.3.0.post2.md)。自动清理保留任务内最终字幕，旧任务回退到记录的导出路径，也可补选原字幕；精修文件不再被误认为缺失的原文件。

这是预览版，不作为 GitHub 最新正式版。已有预览用户可更新；正式版用户只有开启“接收预览版本更新”后才会收到。采用完整更新包，保留任务、模型、配置和知识库。安装器未配置受信任 Authenticode；在线清单使用原 Ed25519 密钥签名。未调用真实模型或执行现有安装上的覆盖更新验收。
