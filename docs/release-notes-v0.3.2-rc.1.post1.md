# Yanami Sub 0.3.2 RC1.1

Windows x64 预览版。核心仍为 FineSub 0.7.1；正式版继续使用 0.3.1.post1。

- **说明气泡**：任务设置中的问号收起低频说明。鼠标悬停、点击或键盘聚焦可查看；必填条件、上传、计费与错误提示仍直接可见。
- **任务反馈**：「开始生成」和「开始批处理」按下会轻微压缩并回弹。「语音识别 / 纠错翻译」只滑动选中背景，支持方向键切换。
- **确实完成才庆祝**：要求的字幕已输出、YouTube 字幕已另存，以及资源/更新就绪会有短促的勾号动效。回退、失败和部分完成仍按原状态显示；进度来自真实数据。应用动效开关和系统「减少动态效果」都能关闭新增动效。
- **继承批处理补丁**：支持逐条设置名称、下载档位和参考文件，运行中追加不会复制上一条的专属设置；只有原始字幕的条目可单独继续翻译。

开启「接收预览更新」即可检查此版本，也可下载 Windows 安装包。不需要清空任务、模型或知识库。

## English

- Optional task explanations move into keyboard-accessible tooltips; critical notices stay visible.
- Single and batch launch buttons respond to presses. Only the selected tab background slides.
- Saved subtitles, ready downloads and genuine success show a brief checkmark effect. Reduced-motion settings are respected and progress stays tied to real data.
- Includes 0.3.1.post1's per-item batch settings and selective translation continuation.
