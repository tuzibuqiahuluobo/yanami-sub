# Yanami Sub 0.1.0 RC6.3

RC6.3 改善 Python 与 AI 依赖安装失败后的恢复方式，并整理“应用更新”和“资源”页面。
内部版本为 `0.1.0-rc.6.post3`；字幕处理核心继续固定为
[FineSub v0.5.1](https://github.com/caca2331/finesub/tree/v0.5.1)。

## 本版更新

- Python 依赖下载增加更宽裕的超时与重试。若锁定的 wheel 安装失败，资源页会显示准确的
  文件名、原始下载链接、缓存目录和可展开的错误日志。
- 用户可手动下载失败的 wheel 并放入提示的缓存目录；再次点击“继续下载”时，应用先核对
  SHA-256，只有匹配锁文件的本地文件才会用于安装。错误哈希不会被静默接受。
- “打开缓存目录”“打开安装目录”改为与其他资源操作一致的圆角按钮。
- “应用更新”的操作按钮与安装提示移至更新说明下方，长公告中不再有悬在正文旁的按钮。

如果失败原因是磁盘空间、文件占用或解压错误，单独手动下载未必能解决；请展开资源卡片的
错误日志继续排查。本版没有改动 FineSub 上游核心，也没有加入单个大型 wheel 的分片下载。

## 安装与更新

- RC5 至 RC6.2：可在“设置 → 应用更新”中检查并安装 RC6.3。这次新增桌面桥接方法，
  在线更新会使用完整包，不会把新前端叠加到旧 EXE 上。
- RC4 或旧版 FineSub Desktop：请手动运行
  `Yanami-Sub-0.1.0-rc.6.post3-Setup.exe` 覆盖安装。
- 新安装：下载 Setup 和对应 `.sha256` 文件，核对一致后运行。

本 Release 同时提供安装器、应用包、完整包、SHA-256 文件以及签名的在线更新清单。
安装包不做付费 Authenticode 证书签名；更新清单的项目签名用于校验下载完整性。
