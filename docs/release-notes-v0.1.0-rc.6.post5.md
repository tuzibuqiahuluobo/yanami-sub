# Yanami Sub 0.1.0 RC6.5

RC6.5 修复 RC6.4 中手动下载的 AI 依赖无法安装，以及 uv 缓存目录缺失导致安装失败的问题。
内部版本为 `0.1.0-rc.6.post5`；字幕处理核心仍固定为
[FineSub v0.5.1](https://github.com/caca2331/finesub/tree/v0.5.1)。

## 本版更新

- 已通过 SHA-256 校验的手动下载 wheel 现在以锁文件的本地路径交给 uv 安装，不再使用被
  uv 拒绝的 `file://` 下载地址。按资源页提供的文件名将 wheel 放入缓存目录后，重新尝试安装即可。
- 若 uv 的 `archive-v0` 缓存目录在安装途中缺失，仅清理出错依赖的 uv 缓存并重试一次，
  不会清空其他依赖缓存；仍失败时保留原始错误和完整安装日志。
- 本地缓存或路径错误不再误判为代理连接问题，避免无意义的代理／直连切换。
- 资源页去掉重复的三行日志预览，只保留一处可展开的安装日志。

本版未改变 FineSub 的依赖版本或哈希，也不承诺网络下载速度。若大文件下载失败，
可先按资源页给出的依赖链接与目标文件名手动下载，再放入缓存目录重新安装。

## 安装与更新

- RC5 至 RC6.4：可在“设置 → 应用更新”中检查并安装 RC6.5。本版修改了冻结启动器，
  在线更新清单会选用完整包，而不是应用层增量包。
- RC4 或旧版 FineSub Desktop：请手动运行
  `Yanami-Sub-0.1.0-rc.6.post5-Setup.exe` 覆盖安装。
- 新安装：下载 Setup 和对应 `.sha256` 文件，核对一致后运行。

本 Release 同时提供安装器、应用包、完整包、SHA-256 文件及签名的在线更新清单。
安装包不做付费 Authenticode 证书签名；在线更新清单仍由项目密钥签名以校验包的完整性。
