# Yanami Sub 0.1.2

正式版，字幕核心仍固定 FineSub v0.5.1。

- 知识库新增独立双语 SRT 导入：原文字幕与人工精修译文逐条严格对齐，支持 UTF-8/BOM、显式 GB18030/CP932。无需原任务、音视频或重新识别；先检查对照，再选条目生成提案。
- 支持额外指定字幕风格条目，从人工译文提炼表达习惯；只吸收长期有用的译名、术语与风格，不整份复制字幕，不伪造 ASR 误听证据。
- 已有任务精修回灌继承 API/Agent 来源、指定 Agent、手动路由、难度及允许更新的风格；只读风格不被悄悄改成可写。
- 提案生成与提交分离，保存同一份正文、绑定与读取版本。应用不再重复调用模型；重复提交、知识库版本变化、部分提交、冲突、无变化有明确结果。
- 知识库停用/回滚等确认使用应用主题弹窗，支持 Esc、焦点约束及默认取消。修正预览/读取操作误报“知识库更新成功”。

## 更新

0.1.1.post4 可直接应用内升级至 0.1.2；RC7.9 也先升至本正式版。之后需要预览版时，在设置主动开启“接收预览版本更新”，再获取 0.1.3 RC1.0。正式用户默认只收到正式更新。

本版使用完整更新包，同步启动器、原生字幕选择器和更新桥接逻辑；原可信签名公钥不变，保留用户任务、模型、知识库及设置。

用法见仓库 `docs/knowledge-subtitle-import.md`。自动化验证使用临时知识库与模拟模型；未消耗真实 API/Agent 配额，不以离线测试保证模型蒸馏质量。
