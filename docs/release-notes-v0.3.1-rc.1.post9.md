# Yanami Sub 0.3.1 RC1.9

Windows x64 预览版；正式版仍为 0.3.0.post5。

- **链接下载档位**：选定网络链接后，在输入文件和处理选项之间显示可调的视频容器、画质、帧率。没有选择的项不显示，未选档位仍用自动下载。精确档位和默认文件分别缓存。
- **工具 → YouTube 字幕下载**：选择视频现有的原有字幕或自动字幕，另存为 SRT、VTT、TXT。不下载视频、不调用模型或转交给第三方字幕网站；不覆盖已存在的文件。
- **FineSub 0.7.1**：合入链接保留视频时纯文本报错、Qwen 和带 BOM 字幕的修复，以及新的模型路由、说话人裁判和转写改进。运行环境锁未变化。
- 新增 ElevenLabs Scribe、MAI2 的 Vercel 凭据、自动／开启／关闭强制对齐、官方游戏术语表、额度暂缓记录及 FineSub 专用 Codex 登录。Intel 和 AMD 支持取决于对应运行环境。

**升级提示：**应用内选择完整更新，并退出旧版让更新程序完成替换。请在「关于／设置」确认运行版本已变成 RC1.9，再重试原任务。仍在原目录且通过校验的已下载视频可复用。

自定义路由的模型 ID、Agent 最低版本和认证变化请见 [FineSub 0.7.1 发布说明](https://github.com/caca2331/finesub/releases/tag/v0.7.1)。
