# Yanami Sub 0.3.0.post1

FineSub 核心仍固定为 v0.7.0，本次不升级上游。

## 重要修复

- 修复 Python 新运行环境反复报 114 项文件内容不符：`onnx` 和 `onnx-weekly` 的共享文件与各自 RECORD 无法同时匹配。按完整发行包识别合法共享文件，仍拒绝缺失、真实损坏、错误版本和逐文件混装，不关闭完整性校验。
- 修复批处理未订阅原生文件拖放、只收到首个文件的问题。支持一次拖入多个音视频并去重；隐藏页面不接收文件。
- 云端转写缺少凭据时，定位并展开新的 API 服务区，不再误跳到模型路由。

## 使用体验

- 模型路由、Agent 配置和就绪检测合并折叠；每个 Agent 一行状态和配置入口。
- API 密钥、联网检索和云端转写服务统一折叠管理；新建任务和批处理共用更清晰的 Agent 设置按钮。
- 任务与批次日志每页 10 条，支持名称筛选、总数和页码回退。
- 知识库默认显示可读正文，模板注释只在高级原文编辑中保留。新增操作说明，切换条目提醒未保存修改。
- 明确知识库查看计划、调用模型及写入的区别；双语导入使用当前核心支持的 Agent。过期的 WorkBuddy 选择需重新确认，不会自动改用可能收费的 CodeBuddy。

## 更新与验证

使用完整更新包以替换原生启动器。保留任务、设置和模型缓存，无需先卸载。旧版安装失败留下的暂存环境会在重试时重新校验。

发布前本机完整后端与打包测试 910 项通过、7 项跳过，前端 145 项通过；类型检查、生产构建和 WebView 静态导出检查通过。已使用按锁校验的官方 ONNX wheel 复现 114 项差异并验证修复，篡改仍被拒绝。浏览器验证日志 10/10/3 分页、折叠引导和多文件原生事件链路。

未运行完整 GPU 字幕任务或付费模型，也未用新安装包进行资源管理器拖放实机验收。知识提取仍需人工审阅；CLI 就绪不代表登录、权限和额度有效。
