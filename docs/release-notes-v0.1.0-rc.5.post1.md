# Yanami Sub 0.1.0 RC5.1

RC5.1 是 RC5 的网络容错修复版，处理核心仍固定为
[FineSub v0.5.1](https://github.com/caca2331/finesub/tree/v0.5.1)。为了与 Python 版本比较
规则兼容，安装包和 tag 使用 `0.1.0-rc.5.post1`，公开版本名为 RC5.1。

## 本版更新

- 修复系统代理的 GitHub API 额度耗尽后，更新检查直接失败而不尝试直连的问题；
- 代理返回 403/429、代理认证失败或临时服务错误时，会自动尝试下一条线路和直连；
- 忽略当前运行环境无法使用的 SOCKS 代理，不再阻断后续线路；
- 所有线路均不可用时，明确提示检查网络、切换网络或暂时关闭代理后重试；
- 更新检查和更新安装异常现在会写入应用会话日志，便于排查真实错误。

## 安装与更新

- 已安装 RC4 或 RC5：请手动下载并运行
  `Yanami-Sub-0.1.0-rc.5.post1-Setup.exe` 覆盖安装；
- 新安装：同时下载安装器及其 `.sha256` 文件，校验一致后运行。

RC5.1 继续不发布在线更新清单，避免仍在使用 RC4 更新器的安装丢失 Windows
卸载器。国内安装包分发源将在确定可持续的国内发布平台后接入；本版不硬编码
不稳定的第三方转发地址。

## 校验与许可

安装包、应用归档和完整归档均附带 SHA-256 校验文件。Yanami Sub 遵循上游当前的
`GPL-3.0-or-later`；详细作者、迁移来源与 prompt 模板许可见 [NOTICE](../NOTICE.md)。
