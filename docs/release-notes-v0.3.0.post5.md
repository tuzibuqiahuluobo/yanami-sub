# Yanami Sub 0.3.0.post5

完整包含 [post4 的下拉菜单、社区共享与本地 Markdown 文件交换改进](release-notes-v0.3.0.post4.md)。最终复查补齐本地导入成功后的正文和编辑缓存刷新：不会出现数据库已写入、返回条目页却仍显示旧内容的情况。不会为刷新再次调用模型。
