# Yanami Sub 0.3.0.post3

FineSub 固定为 v0.7.0（7123055），本次不修改或升级上游源码。上游 eager 校验异常处理缺口已报告为 [FineSub #19](https://github.com/caca2331/finesub/issues/19)；尚未认定原任务的底层内核失效原因。

## 桌面端兼容修复

- 单任务与批处理共用 Worker 兼容层，覆盖本地 Qwen 二次识别校验（含字幕稳定化补救）中的 CUDA SDPA `No available kernel` / `No viable backend for scaled_dot_product_attention`。
- 仅在匹配当前固定 Torch 2.11.0 / Transformers 5.14.1 且遇到明确的内核不可用错误时，用模型自己的标准 eager 注意力重试一次。仍使用原 GPU、原输入和 token 上限；成功后该模型实例继续使用兼容实现。不修改全进程注意力开关，不干扰并行分离。
- 正常路径不变；显存不足、设备异常、数据错误等不因此被吞掉。重试仍失败时停止任务并给出原因，不跳过校验、不伪造成功。
- 日志显示兼容尝试、设备、精度、输入 token 形状和后端状态，以及重试是否恢复。兼容实现可能更慢或增加显存。

## 验证与边界

使用本机已有的 Qwen3-ASR-0.6B 权重，在 RTX 4060 Ti 16 GB / Torch 2.11.0+cu128 上，强制不可用的 Flash-only 后端，实际触发同类错误；桌面兼容处理成功切换模型内 eager 并完成两次离线 GPU 推理，峰值 Torch 分配约 1.49 GiB，进程级后端开关保持不变。输入为两秒合成静音，不是原任务，也不是长音频识别质量验收。没有下载额外模型或调用付费 API。

新增回归覆盖正常路径不变、有界重试、参数保留、仅限 GPU、重复初始化、错误类型不变及失败不冒充成功。发布还须通过云端完整测试、产物身份/哈希及更新签名检查。

采用完整更新，保留模型、任务、配置及知识库，无需卸载；建议从历史记录重试原任务，已有阶段能否复用仍由核心缓存校验决定。未执行原故障长视频或现有安装上的覆盖更新验收。安装器没有受信任 Authenticode 证书；应用内更新清单使用原 Ed25519 信任密钥签名。
