# Yanami Sub 0.2.2 RC1.0

预览版，规范版本与标签为 `0.2.2-rc.1` / `v0.2.2-rc.1`。与同期正式版 0.2.1 共用 FineSub v0.6.0 固定核心及同一批迁移、知识库、运行环境和下载修复；没有额外宣称尚未实现的预览功能。

- 单任务与批处理使用 0.6.0 接口，独立 CodeBuddy 替代旧 WorkBuddy 桌面通道；旧登录凭据不复用，不自动切换付费模型。
- 知识库迁移前先备份校验，精修风格和证据跟随冻结提案；修复重试重复字幕、依赖修复参数、下载回退策略和中文编译诊断解码。
- 采用完整更新包及签名 v2 发现入口，保留任务、模型与设置；首次使用可能需要按新依赖锁重建 Python 环境。

## 更新通道

0.2.1 正式版需主动开启“接收预览版本更新”才能收到本版。0.1.2 正式版也可在开启预览后直接升级；较旧 RC7 客户端建议先升级 0.2.1，再选择预览通道。预览版默认接收更高版本的 RC 与正式版，不会降级至数字版本更低的 0.2.1。

本版与正式版具有相同验收边界：完整可选 AOTI 仍有加载异常并可回退 eager CUDA，全新大模型在线下载未完整验收，真实 API/Agent 账号与完整安装升级演练未覆盖；不保证所有显卡、网络或供应商账号。详细内容及升级注意事项见 [0.2.1 公告](https://github.com/tuzibuqiahuluobo/yanami-sub/releases/tag/v0.2.1)。

在线更新清单使用原有 Ed25519 信任密钥，安装器无 Windows Authenticode 发布者证书。升级前建议备份知识库和自定义配置；自动迁移备份不等于一键降级。
