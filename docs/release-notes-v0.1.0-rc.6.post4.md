# Yanami Sub 0.1.0 RC6.4

RC6.4 改善 Python 与 AI 依赖在国内外网络下的下载与失败恢复。内部版本为
`0.1.0-rc.6.post4`；字幕处理核心仍固定为
[FineSub v0.5.1](https://github.com/caca2331/finesub/tree/v0.5.1)。

## 本版更新

- 桌面运行环境改用官方 uv 0.12.17。uv 在服务器支持时可对中断的 wheel 传输使用 HTTP
  Range 重试；FineSub 的依赖锁及哈希未修改。
- 自动线路在开始安装前，对锁文件中的 PyTorch 官方源和国内镜像做有上限的小样本测速；
  只有差距明显且国内镜像的 PyPI 端可访问时才调整优先级。手动选择的线路不会被覆盖。
- 网络错误时可尝试从代理改为直连，并在自动线路下尝试另一套已锁定的下载源。
  暂停、磁盘错误与校验错误不会被当成网络故障重试。
- 修复新版 uv 对国内锁文件命名的兼容问题；安装时使用字节内容相同、名称符合要求的
  临时锁文件，不改变上游锁文件。
- 资源页显示当前线路和可展开的安装日志。AI 依赖阶段不再误用 uv 压缩包的下载百分比。

小样本测速只能帮助选择起始线路，不代表 2.6 GB 级依赖的持续速度；下载仍受用户网络、
代理、镜像和源站状态影响。本版不加入自制分段下载，也不降低 TLS 或 SHA-256 校验要求。
若某个 wheel 仍下载失败，可按资源页提示手动下载到缓存目录后重试。

## 安装与更新

- RC5 至 RC6.3：可在“设置 → 应用更新”中检查并安装 RC6.4。本版修改了冻结启动器，
  在线更新清单会选用完整包，而不是应用层增量包。
- RC4 或旧版 FineSub Desktop：请手动运行
  `Yanami-Sub-0.1.0-rc.6.post4-Setup.exe` 覆盖安装。
- 新安装：下载 Setup 和对应 `.sha256` 文件，核对一致后运行。

本 Release 同时提供安装器、应用包、完整包、SHA-256 文件及签名的在线更新清单。
安装包不做付费 Authenticode 证书签名；在线更新清单仍由项目密钥签名以校验包的完整性。
