# Yanami Sub 0.2.2 RC1.1

规范版本／标签：`0.2.2-rc.1.post1` / `v0.2.2-rc.1.post1`。

本预览版包含正式补丁 `0.2.1.post1` 的全部功能补齐与修复：可选说话人标签和分轨导出、任务级预设默认继承、运行中追加批次、实验性 Agent 协作、知识库结构整理和已校验恢复点。

核心仍固定为 FineSub v0.6.0（`5caf422cbad36f0402c98eb565e4c29aee4ac197`），不另改识别算法。

- `0.2.2-rc.1` 用户可通过应用内升级本补丁；正式版用户只有开启“接收预览版本更新”才会收到本预览。
- 新增原生桥接接口，采用完整更新包同步启动器与应用，保留运行环境、模型、设置和任务；不提供运行中热替换或降级覆盖。
- 验证范围与限制同[正式补丁说明](https://github.com/tuzibuqiahuluobo/yanami-sub/blob/v0.2.1.post1/docs/release-notes-v0.2.1.post1.md)：声学／导出有隔离实测；裁判、真实 Agent 账号和多人准确度未实测。功能默认关闭，按需启用；不自动消耗账号额度。
- 下载与签名使用原信任公钥。安装器没有 Windows Authenticode 发布者证书；更新前请备份重要知识与自定义配置。
