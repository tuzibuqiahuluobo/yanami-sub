# Yanami Sub 0.1.0 RC6.10

RC6.10 改善字幕任务的模型来源选择、失败恢复和日志体验。内部版本为
`0.1.0-rc.6.post10`；字幕处理核心仍固定为
[FineSub v0.5.1](https://github.com/caca2331/finesub/tree/v0.5.1)，未合并上游新代码。

## 本版更新

- 新建任务和批处理可选择“自动”“API”“本地 Agent”或手动模型路由。自动模式在填有
  Gemini Free 密钥时优先使用免费 API，否则使用已检测到的本地 Agent。
- 本地 Agent 按设置中的顺序尝试；可回退的故障会尝试下一候选，并在完整任务日志中记录
  失败目标与可获取的原因。若所有 Agent 均无法完成纠错翻译，保留原始字幕并在界面打叉
  标记该阶段跳过，不会把原始字幕误称为译制成品。
- 修复字幕已生成后，后置知识库更新因 DSH 额度等原因失败却导致整项任务报错的问题。
  此时跳过本次知识库更新并交付已生成的字幕，日志仍保留失败原因。
- “导出日志”现在保存完整的磁盘任务日志，而非有限的界面日志片段；成功后可一键打开
  保存位置。离开新建任务页时，右下角显示处理进度，完成后给出成功提示。
- 改善 Windows 原生工具与中英文混合的字幕处理日志编码；模型下载的 Hugging Face
  匿名访问及无符号链接提示更加简洁，真实下载错误不被隐藏。

## 安装与更新

- RC6.9 可在“设置 → 应用更新”或启动更新公告中下载 RC6.10。本次包含启动器和桥接层
  改动，在线更新将提供**完整包**，而不是应用内的小包；下载后按提示退出并安装。
- 应用无法启动或网络无法完成应用内更新时，从本 Release 下载
  `Yanami-Sub-0.1.0-rc.6.post10-Setup.exe` 与同名 `.sha256` 校验后覆盖安装；无需先卸载，
  不要清理用户数据或已有字幕。
- Agent 的认证/永久性错误与能力不匹配不保证自动跨模型恢复；请查看任务日志中的原因，
  必要时切换来源或修复相应 Agent。恢复路径不会伪造翻译结果。

本 Release 同时提供安装器、应用包、完整包、各包 SHA-256，以及项目密钥签名的
**在线更新清单**。安装包没有付费 Authenticode 证书签名。
