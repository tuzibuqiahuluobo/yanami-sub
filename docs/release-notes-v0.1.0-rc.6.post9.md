# Yanami Sub 0.1.0 RC6.9

RC6.9 修复 RC6.8 中部分用户下载 Whisper 等 AI 模型时因本机 SOCKS 代理拒绝连接
（`WinError 10061`）而直接失败的问题。内部版本为 `0.1.0-rc.6.post9`；字幕处理核心
仍固定为 [FineSub v0.5.1](https://github.com/caca2331/finesub/tree/v0.5.1)。

## 本版更新

- 模型下载会核对当前可用代理线路；代理发生连接类错误时尝试下一连接方式，而不再把
  同一个失效代理带到所有重试中。
- 自动选择的官方模型源发生连接类错误后，可尝试应用内置的国内 Hugging Face 镜像。
  用户明确指定的模型源仍优先遵从；网络中断不会被误记为镜像损坏。
- 普通任务启动时也会清理从父进程继承的失效代理变量。模型下载最终失败时，提示用户
  检查代理或切换网络，并保留原始错误日志供排查。
- 保留原有模型缓存、代理设置、用户数据与固定的模型版本；不改变上游 FineSub 核心。

## 安装与更新

- 可在 RC6.8 的“设置 → 应用更新”检查并下载 RC6.9。本次修复涉及冻结的启动器，
  在线更新提供完整包；退出旧进程后安装并重新打开应用。
- 如果应用无法打开或 GitHub 网络不可达，可下载
  `Yanami-Sub-0.1.0-rc.6.post9-Setup.exe` 与同名 `.sha256`，校验哈希后覆盖安装。
  RC6.6 若启动时遇到 WinError 448，也应使用 Setup 覆盖安装，无需卸载或清理用户数据。
- 连接方式与镜像回退只能提高恢复机会，无法保证任何网络环境始终可访问。两条线路
  都失败时，请确认代理服务是否正在运行，或切换网络后重试。

本 Release 同时提供安装器、应用包、完整包、SHA-256 文件，以及项目密钥签名的
在线更新清单。安装包不使用付费 Authenticode 证书签名。
