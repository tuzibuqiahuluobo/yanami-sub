# Yanami Sub 0.1.0 RC7.4

RC7.4 是 0.1.1 正式版的更新通道过渡版本。字幕核心继续固定为 FineSub v0.5.1；本版不升级上游核心。

## 本版改进

- 修复 RC 启动器只能发现 RC、无法升级正式版的问题。RC 用户默认接收版本号更高的 RC 与正式版；正式版用户默认只接收正式版，在设置中开启“接收预览版本更新”后才会收到版本号更高的 RC。
- 跨 RC/正式通道更新强制使用完整包，以一并更新冻结启动器和通道配置；所有更新仍验证原 Ed25519 密钥签名、平台、版本与文件哈希。
- 魔理沙和八奈见杏菜主题改为浅色基底，保留各自的金色与海蓝/四叶草配色，并改善浅色底上的文字、按钮对比度。

## 升级说明

RC7.3 及更早的启动器无法直接发现正式版。请先在应用内安装 RC7.4 完整更新，再检查并安装 0.1.1 正式版。此过渡不清除用户数据。若应用无法启动，可使用 0.1.1 安装器覆盖安装。

发布资产包含安装器、app/full ZIP、SHA-256 文件与签名在线更新清单。RC7.4 从旧 RC 升级使用完整包。

## 已知边界

- 预览版必须比本机版本号更新才会提示；0.1.1 正式版之后的下一轮 RC 应使用 0.1.2 或更高版本基线，不能用旧于 0.1.1 的 RC 覆盖正式版。
- 安装器未附 Windows Authenticode 签名；在线更新清单使用原 Ed25519 密钥签名并验证 ZIP 哈希。
