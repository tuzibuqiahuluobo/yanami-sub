# Yanami Sub 0.1.2 RC7.5

RC7.5 修复应用内更新后反复回到旧版的问题，并改善更新说明和系统日志入口。字幕核心继续固定为 FineSub v0.5.1；本版不升级上游核心。

## 修复与改进

- 修复 Python 首次启动生成的 `__pycache__/*.pyc` 被安装完整性校验误判为额外文件，导致健康确认失败、下次启动回滚并再次提示更新的问题。发布清单中的所有文件仍逐一校验大小和 SHA-256；未列出的源代码文件仍被拒绝。
- 完整更新器不再复用哈希不符的目标版本目录；对拷贝后的版本再次校验。更新未生效或健康确认失败时，会留下明确的会话日志及设置页提示，不再静默循环。
- 修复 [Issue #2](https://github.com/tuzibuqiahuluobo/yanami-sub/issues/2)：更新说明和完成提示改为纵向布局，不再被开关行样式挤成窄列。
- 在设置页最底部显示系统日志目录，并提供“打开日志位置”。中英文界面均已补齐。

## 升级说明

- RC7.4 用户默认可在应用内检查到 RC7.5；0.1.1 正式版用户需先在“设置 → 应用更新”开启“接收预览版本更新”。RC7.5 版本号高于 0.1.1，因此不会被误判为降级。
- 此次变更涉及冻结启动器，应用内更新使用已签名的完整包，保留现有任务、模型和设置。若旧安装已经无法启动，可退出应用后运行本版安装器，选择原安装目录覆盖安装，无需卸载。
- 正式版用户若不启用预览更新，不会收到 RC7.5；后续更高版本的正式版仍按正式通道推送。

发布资产包含完整安装器、app/full ZIP、SHA-256 文件与原 Ed25519 密钥签名的在线更新清单。安装器未附 Windows Authenticode 签名。
