# Yanami Sub 0.3.0.post2

FineSub 核心保持 v0.7.0。本补丁修复知识库学习文件定位，并改善操作提示与界面布局。

## 问题原因与修复

- 原任务成功导出字幕到源媒体旁后，清理功能可能删除任务目录内的最终字幕；精修学习仍按内部旧路径读取，导致报“文件不存在”，即使用户新选的精修文件存在。
- 新任务自动清理和历史手动清理均保留内部最终字幕。旧任务只回退到历史记录里的 `finalSrt` 导出位置，不盲猜其他文件、不拿精修译文冒充原字幕。
- 原字幕移动后可以手动补选。原字幕与精修文件在进入模型路由前验证，错误说明缺少哪一份材料及解决方法。识别材料、风格与上下文仍沿用原任务目录，不因导出文件改名而错配。

## 界面改进

- 双语字幕导入和已有任务精修学习增加步骤、下一步提示；显示原任务字幕位置与补选入口。
- 精修错误就近显示，不再出现在无关的检查与恢复页面；应用已经审阅的提案不会再次调用模型。
- 知识库下拉菜单统一圆角样式，支持键盘滚动长列表和根据空间向上或向下展开。
- 维护工具的按钮按卡片实际空间换行，长路径可换行，避免半宽卡片溢出。

## 更新与验证

采用完整更新包替换含桥接修复的启动器。保留模型、任务、设置与知识库，无需先卸载。若旧任务的内部和导出字幕均已删除，仍需用户补选原字幕；不会凭空恢复文件。

本机完整 Python 回归 913 项通过、7 项跳过；前端 147 项通过，类型检查及生产构建通过。真实浏览器完成 160 个知识库标签页布局检查（中英文、深浅色、16/20px 字体、375–1600px 宽度），并验证文件角色、就近报错、固定提案应用、长列表键盘导航。另加入可持续运行的卡片边界回归测试。

未运行付费模型、真实 GPU 任务或在现有安装上执行覆盖更新。安装器未配置受信任的 Authenticode 证书；应用内更新清单使用原 Ed25519 信任密钥签名。
