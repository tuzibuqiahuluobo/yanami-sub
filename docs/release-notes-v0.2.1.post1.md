# Yanami Sub 0.2.1.post1

0.2.1 功能补齐与修复补丁。FineSub 核心保持 v0.6.0（`5caf422cbad36f0402c98eb565e4c29aee4ac197`），不升级模型或修改识别算法。

## 更新内容

- 新建任务与批处理增加可选说话人分离、文字／音频裁判、模型与人数上限设置，以及独立分轨 SRT／ASS 导出。默认关闭；普通字幕不变。新增阶段、产物与跳过原因同步显示，复用现有文件保护，不覆盖用户手改字幕。
- 增加任务级路由预设，可明确选择跟随预设默认参数或自定义。默认值由上游解析，快速预设不再被桌面固定的质量／串行／单窗口覆盖；旧任务的显式参数保留。任务知识库回灌继承该选择。
- 批处理运行中可追加文件或 URL，沿用该批次保存的参数。先保存、再交由上游调度器接收；结束瞬间追加的项目保留为可继续状态，重启恢复不重复入队。
- 增加实验性 Agent 协作入口：查看本应用等待中的文字任务，生成接入说明交给用户自己的 Agent。说明固定使用本应用解释器，沿用上游注册、租约和结果校验；不会自动发消息、启动 Agent 或探测付费额度。
- 知识库增加小节拆分／整节移动，先预览再应用同一份冻结操作，保留行 ID 与历史；修订变化则拒绝过期提案。成功、拒绝和提交后的投影刷新异常分别提示。
- 知识库维护增加本机迁移恢复点：校验、准备独立副本、确认后启用。启用前保留当前库与回退快照，隔离旧提案，不恢复配置或密钥；中途退出时阻止创建空库，并提供安全收尾入口。

## 升级

- 正式版默认接收本正式补丁；开启预览更新后可选择 `0.2.2-rc.1.post1`。预览用户继续接收更高版本的预览，不改变既有渠道规则。
- 本轮新增原生桥接接口，应用内更新使用完整更新包同步启动器与应用，不是运行中热替换前端。保留运行环境、模型缓存、设置和任务；签名信任公钥不变。
- 无法应用内更新时，退出应用后用 Setup 选择原目录覆盖安装，不需要先卸载或删除模型。

## 验证与限制

- 完成后端、前端、打包回归；在隔离托管环境用 40 秒真实素材完成 Nemotron-3 声学标签与分轨 SRT／ASS 导出，检查中日文路径及 UTF-8 输出。首次下载约 450 MB，速度依赖网络。该样本只有单个声轨，不构成多人、跨语言准确度评测。
- 文字／音频裁判和用户自己的 Agent 仍属实验性，本次未调用真实账号或外部 LLM；裁判可能消耗模型额度。音频裁判缺少上游生产验收。轨号不等于人物身份，可能需要人工合并和校对；人数上限建议留空。
- DiariZen 仅限非商业研究；Sortformer 需要用户自行导出模型。默认 Nemotron-3 组合可商用；不承诺所有显卡、语言或场景的识别质量与固定提速。
- 恢复点包含私人知识与配置备份，应只在本机保管，不要直接作为公开反馈附件。恢复不是整个应用的一键降级；请勿运行中手动覆盖数据库。
- 安装器未配置 Windows Authenticode 发布者证书；在线更新清单使用既有 Ed25519 密钥签名。
