# Yanami Sub 0.2.2 RC1.2

预览版 `0.2.2-rc.1.post2` 包含正式补丁 `0.2.1.post2` 的资源引导与界面反馈修复，FineSub 核心仍为 v0.6.0。

- 首页资源安装按钮显示真实下载、暂停与失败状态。
- 新建任务和批处理缺少资源或配置时提供原因、精准定位和返回入口；必需资源持续黄色提示，返回后保留任务草稿。
- 公共确认弹窗、下拉框、折叠区域与通知增加柔和交互，支持减少动态效果。

本预览沿用独立更新渠道；正式版用户需要主动开启预览更新。桥接字段已调整，应用内更新使用完整更新包，保留模型、设置与任务。签名公钥不变。

后端、前端和打包回归已通过；隔离环境验证了 yt-dlp 的实际下载与跨页提示。尚未取得原用户批处理故障的具体日志，也未使用真实模型或账号重跑完整字幕任务。安装器未配置 Windows Authenticode 发布者证书。
