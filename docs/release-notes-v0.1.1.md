# Yanami Sub 0.1.1

Yanami Sub 首个正式版。字幕核心继续固定为 FineSub v0.5.1；本版不升级上游核心。

## 改进

- 魔理沙与八奈见杏菜主题以浅色为主，保留各自的金色、海蓝和四叶草配色，并改善文字与控件对比度。
- 正式版默认只检查更高版本的正式版；如需体验未来版本，可在“设置 → 应用更新”开启“接收预览版本更新”。开启后也只会提示高于当前版本的 RC。
- RC 用户默认可以收到更高版本的 RC 与正式版。跨 RC/正式版更新使用完整包，以一并切换冻结启动器的更新通道。
- 延续 RC7.1–RC7.4 的 Agent 选择、任务记录、下载诊断、签名更新和界面修复。

## 从 RC 升级

- RC7.4 用户可在应用内检查并安装 0.1.1 正式版；这是完整更新，不会清除用户任务和设置。
- RC7.3 及更早的启动器无法直接发现正式版。请先在应用内安装 RC7.4，再检查并安装 0.1.1；也可以退出应用后运行 0.1.1 安装器，并选择原安装目录覆盖安装。
- 正式版之后的新 RC 需要采用高于 0.1.1 的版本号，例如 0.1.2 RC；低版本 RC 不会作为更新推送。

发布资产包含安装器、app/full ZIP、SHA-256 文件与原 Ed25519 密钥签名的在线更新清单。安装器未附 Windows Authenticode 签名。
