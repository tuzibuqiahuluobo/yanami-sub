# Yanami Sub 0.1.0 RC5.2

RC5.2 是 RC5 的界面细节优化版，处理核心仍固定为
[FineSub v0.5.1](https://github.com/caca2331/finesub/tree/v0.5.1)。为了与 Python 版本比较
规则兼容，安装包和 tag 使用 `0.1.0-rc.5.post2`，公开版本名为 RC5.2。

## 本版更新

- 统一输入框、批处理链接输入区、知识库表单和下拉菜单的圆角与交互状态；
- 为新建任务、批处理的语音识别 / 纠错翻译切换，以及知识库页面切换加入主题色过渡；
- 模型路由目录改为带平滑展开和收起效果的可访问控件；
- 所有新增过渡统一受“界面动画”开关控制，关闭后立即切换，首次安装默认开启；
- 系统启用“减少动态效果”时自动停用切换过渡，避免造成视觉不适。

## 安装与更新

- 已安装 RC4、RC5 或 RC5.1：请手动下载并运行
  `Yanami-Sub-0.1.0-rc.5.post2-Setup.exe` 覆盖安装；
- 新安装：同时下载安装器及其 `.sha256` 文件，校验一致后运行。

RC5.2 继续不发布在线更新清单，避免仍在使用 RC4 更新器的安装丢失 Windows
卸载器。安装包、应用归档和完整归档继续作为独立下载提供。

## 校验与许可

安装包、应用归档和完整归档均附带 SHA-256 校验文件。Yanami Sub 遵循上游当前的
`GPL-3.0-or-later`；详细作者、迁移来源与 prompt 模板许可见 [NOTICE](../NOTICE.md)。
