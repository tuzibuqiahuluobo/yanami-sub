# Yanami Sub 0.1.0 RC7.3

RC7.3 改进本地 Agent 路径与就绪状态的呈现。字幕核心仍固定为 FineSub v0.5.1；本版不升级上游核心。

## 本版改进

- 本地 Agent 就绪检测会返回结构化 CLI 路径，并自动预填到对应 Agent 的自选安装路径。预填不会自动写入设置，用户仍需主动保存；手动输入或已保存的路径不会被覆盖。支持保存检测到的 npm DSH CLI 路径。
- 五个 Agent 的自选路径改为默认收起的可展开列表；从任务页跳转到 Agent 设置时会自动展开。左下角增加本地 Agent 状态，检测到就绪的模型后显示“本地 Agent 已连接”，并避免将 Agent 可用误标为 Gemini 已连接。
- 输出名称为空时，最终字幕默认以源媒体文件名加 `.srt` 发布。输入框显示“默认：原文件名.srt”；若同名文件不能安全覆盖，则沿用现有的 `.finesub.srt` 避让规则。

## 安装与更新

RC7.3 修改了冻结启动器的 Agent 探测接口，因此从 RC7.2 更新使用完整更新包；应用内可以下载并完成更新。无法启动的旧版本可用 RC7.3 Setup 覆盖安装，无需卸载或清除用户数据。

发布资产包括完整安装器、app/full ZIP、SHA-256 文件以及由原 Ed25519 私钥签名的在线更新清单。应用 ZIP 仅供兼容旧更新协议的发布资产使用，RC7.3 更新清单将选择完整包。

## 已知边界

- Agent 就绪检测只检查 CLI、版本和本机环境，不发送真实模型请求；账户、权限、额度和远端服务仍需以实际任务结果为准。
- 对非最终字幕阶段，输出后缀由所选阶段决定，不一定是单纯的 `.srt`。
