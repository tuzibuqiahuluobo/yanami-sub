# Yanami Sub 0.1.0 RC7.2

RC7.2 改进任务路由与操作体验。字幕核心仍固定为 FineSub v0.5.1；本版不升级上游核心。

## 本版改进

- 新建任务和批处理都可指定一个本地 Agent（AGY、Claude Code、Codex、DSH、WorkBuddy）。不指定时仍使用原有自动尝试顺序；不可用的候选会继续回退并在任务日志中留痕。
- 修正 FineSub 0.5.1 对部分 HTTP 连接/协议中断的永久错误判定，让手动模型路由在这类临时故障后继续尝试候选。无效密钥等 4xx 错误不会被伪装成网络故障。
- 设置中可分别填写各本地 Agent 的非标准安装路径，并提供探测失败的排查提示。缺少 Gemini API 密钥时直接定位对应输入框；输入框统一显示“输入 API 密钥”，并隐藏 WebView2 额外的原生显隐控件。
- 移除处理页面重复的“导出日志”按钮；失败任务可直接返回“新建任务”。历史任务可长按或右键显示删除记录操作，删除前确认，且不会删除媒体、字幕和任务产物。
- RC7.1 及后续版本的应用包均强制要求逐文件 SHA-256 清单，避免未来补丁版意外放宽完整性检查。

## 安装与更新

RC7.2 修改了冻结启动器的桥接接口，因此从 RC7.1 更新使用完整更新包；应用内可下载并完成更新。无法启动的旧版本可用 RC7.2 Setup 覆盖安装，无需卸载或清除用户数据。

发布资产包括完整安装器、app/full ZIP、SHA-256 文件以及由原 Ed25519 私钥签名的在线更新清单。应用 ZIP 仅供兼容旧更新协议的发布资产使用，RC7.2 更新清单将选择完整包。

## 已知边界

- Agent 就绪检测只验证命令可用性，不能保证账户、权限、余额或远端模型一定可用；以实际任务日志为准。
- 历史记录删除只移除应用内索引。任务产物仍留在数据目录，需由用户确认路径后自行清理。
