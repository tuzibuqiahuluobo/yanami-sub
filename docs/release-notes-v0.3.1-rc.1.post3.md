# Yanami Sub 0.3.1 RC1.3

内部版本 `0.3.1-rc.1.post3`。包含与正式版 0.3.0.post3 相同的桌面 Qwen CUDA 注意力兼容处理；FineSub 固定 v0.7.0，不修改上游源码。

详细行为和验证边界见 [0.3.0.post3 修复说明](release-notes-v0.3.0.post3.md)。只对明确的注意力内核不可用错误进行一次模型内 eager 重试，成功后继续在原 GPU 校验；不修改全进程后端开关，不吞掉其他错误，不静默跳过校验。

已通过本机缓存模型的两秒合成音频离线 GPU 验收，但尚未复跑原故障长视频或验证所有 GPU。预览用户可直接更新；正式用户仅开启预览更新时收到。采用完整更新包，保留任务、配置、模型与知识库。没有受信任 Authenticode 证书；更新清单使用原 Ed25519 密钥签名。
