# Yanami Sub 0.1.1.post4

字幕核心仍固定为 FineSub v0.5.1，不升级上游模型或驱动，不改变识别参数。

## 改进与修复

- 隐藏启动、设置页本地 Agent 就绪检测及任务 CLI 预检的 CMD 控制台窗口，避免多个黑窗闪现；主动打开的登录交互界面不受影响。
- 启动时先显示原生进度小窗，展示安装校验、运行环境准备及逐项 Agent 检测；检测结束且主页面载入后关闭小窗并显示主界面，复用现有组件，不新增 GUI 依赖。
- 主界面复用启动检测结果，不再自动重复扫描；并发检测请求合并，稍后点击“开始检测”仍会重新检查。
- 每个 CLI 探测子命令最多 15 秒，整轮 CLI 能力检测预算 60 秒；异常、不可用或超时保留结果，不阻止打开主界面。此预算不含安装校验、路径发现和页面加载。
- 会话日志记录各检测项、状态与耗时；单实例激活在启动小窗和主窗口之间正确交接。关闭小窗可取消启动，当前已运行的探测会在有界超时内结束。

## 更新方式

正式版用户无需开启预览更新即可收到本版，默认不会收到 RC 更新。
本次包含冻结启动器修复，旧版本使用完整更新包。若旧版无法启动，请完全退出后在原位置覆盖安装，无须先卸载；保留设置、任务和模型。

## 验证范围

- 就绪检测仅检查本机 CLI、版本和所需能力，不请求模型，不代表登录有效、模型授权或额度充足。
- 已验证启动成功、异常、超时、取消、重复启动交接和实际检测子进程没有控制台；原生小窗至隐藏 WebView、主界面显示和正常退出的集成检查通过。
- 用户提供的 RC7.8 应用快照校验及最新会话均正常，日志没有记录现场卡死；本版修复已确认的黑窗与检测等待缺口，不宣称已经复现所有无响应场景。

构建使用 GitHub Actions；在线更新清单由既有可信 Ed25519 私钥在本地签署，私钥不上传仓库或云端。
