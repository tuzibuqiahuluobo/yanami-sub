# Yanami Sub 0.1.0 RC7.1

RC7.1 在 RC7 基础上修复任务可靠性与安全边界。字幕主流程仍使用 FineSub v0.5.1；本版不引入新的上游核心版本。

## 本版改进

- 纯文本本地 Agent 的媒体降级现在传入实际处理管线；混合回退组只在所有候选均支持所选媒体时保留多模态要求。API 与 Agent 来源选择继续在新建任务和批处理中共用。
- 设置中可手动指定非标准安装位置的 DSH。探测遇到失效路径、重解析点或 Windows 访问错误时不再中断启动；`--version` 退出非零不会误报就绪。
- 任务页显示模型来源和折叠的候选尝试顺序，右下角进度球与任务页同步显示可信的阶段计数。候选顺序不代表某个模型已成功调用。
- API 只有在确认是纠错模型调用的可恢复失败、且已有原始字幕时才降级；磁盘和其他阶段异常不再伪装成“纠错已跳过”。
- 发布到源文件旁的字幕由独立摘要记录保护：手工修改、同名不同媒体源都不会被无声覆盖。
- 应用包新增逐文件 SHA-256 清单；安装、启动和健康确认共用验证，残缺版本会尝试回退到最近的完整版本。健康确认延后到前端实际完成首次绘制和桥接往返。
- 卸载器不再按进程名强制关闭同名便携程序，也不再递归删除自选安装目录下的运行环境、模型或缓存；必要时用户可核对路径后自行清理残留。

## 安装与更新

RC7→RC7.1 因启动器变化使用完整更新包，但仍可在应用内下载并更新。无法启动的旧版可运行本版 Setup 覆盖安装；不需要先卸载或清空用户数据。每个发布资产附有 SHA-256，在线更新清单采用原 Ed25519 发布密钥签名。

本版同时提供完整安装器、app/full ZIP、签名在线更新清单及 SHA-256 文件。发布 tag、源提交和包内 `app-manifest.json` 可用于核对来源。

## 已知边界

- 本地 Agent 的版本探测不能验证账户余额或真实推理响应；实际调用结果以任务日志为准。
- 历史 Git 提交中曾包含测试产物和用户路径；RC7.1 的当前源码树已清理并加入忽略规则，但要从 GitHub 历史彻底移除仍需另行协调历史重写和缓存清理。
