# Yanami Sub 0.3.1 RC1.4

对应版本：0.3.1-rc.1.post4；预览频道。包含 0.3.0.post4 的同一批下拉菜单、默认社区地址和本地 Markdown 文件交换修复，固定 FineSub v0.7.0。

改动、共享步骤、验证范围与限制详见[正式版同批说明](release-notes-v0.3.0.post4.md)。本次不新增视频压制功能，不会自动上传本地知识或调用模型。

采用完整更新包，保留任务、设置、知识库和模型缓存。正式版默认不接收本预览版，开启“接收预览版本更新”后才提示。预览版可升级更高预览版或正式版，不降级。

更新清单仍使用原有 Ed25519 密钥签名；安装器没有 Windows Authenticode 发布者证书签名。默认社区仅做公开快照只读检查，未真实注册投稿；未运行原地安装或完整长视频任务。
