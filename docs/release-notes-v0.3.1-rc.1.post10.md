# Yanami Sub 0.3.1 RC1.10

Windows x64 预览版；正式版仍为 0.3.0.post5。

- 修复 YouTube 等链接手选档位时，数字编号明明存在却报「所选格式不可用」的问题，例如 MP4 1080p 60 fps。
- 列表不显示无法确认音视频轨道或仅有受保护音轨的档位。如果手选档位在下载前失效，会提示重新选择或「恢复自动」，不会擅自降低画质。其他网络错误仍照常报告。
- 「恢复自动」和「重试」改用统一的圆角按钮，切回自动时标题不跳动。

从 RC1.9 升级时，在应用内选择完整更新，并退出旧版完成替换，再重试原任务。仍使用 FineSub 0.7.1，不需要重装 Python 运行环境。
