# Yanami Sub 0.3.1.post1

Windows x64 正式版，包含 0.3.1 的主要更新与首个补丁。核心仍为 FineSub 0.7.1。

## 0.3.1 的主要更新

- **链接和字幕命名**：视频下载后进入同一套字幕流程，可选格式、画质和帧率。链接成品默认用视频标题，取不到时用本机日期时间；手填名称优先。
- **YouTube 字幕工具**：可单独另存现有字幕为 SRT、VTT 或 TXT，不下载视频或调用模型。
- **节目参考和分轨**：可给单任务配节目切片与字幕，按时、分、秒、帧预览对齐，并把确认过的说话人轨道分组导出。
- **FineSub 0.7.1**：包含链接、Qwen、字幕兼容和转写改进，以及术语表、额度记录和 FineSub 专用 Codex 登录。

## 0.3.1.post1 的修复

- **每条单独设置**：在批处理队列逐条指定下载档位、字幕名称、补充视频和人工精修字幕。运行中追加不会复制上一条的专属素材；旧清单误共享同一参考文件时会提示修正。
- **只补译一条**：批次结束后，只有原始字幕的项目可打开本条的翻译设置，复用仍在的识别文件，无需重跑整个批次。翻译跳过状态在续跑后仍可识别。
- **边界保护**：参考文件已丢失会明确提示，单条错误不覆盖其他项目的成品。批处理与单任务使用同样的代理环境处理，并在个别旧历史记录不可读时保留其余记录。

**升级**：0.3.1 正式版可以直接完整更新到 0.3.1.post1。任务、知识库、模型和运行环境无需清空。本次不发布新的预览版；节目参考对齐仍仅支持单任务。
