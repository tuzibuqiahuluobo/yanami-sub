# Yanami Sub 0.1.3 RC1.0

预览版，规范版本/标签为 `0.1.3-rc.1` / `v0.1.3-rc.1`，字幕核心仍固定 FineSub v0.5.1。

包含正式版 0.1.2 的双语 SRT 知识导入、完整任务模型/风格继承、保存并应用同一份提案、准确结果提示及主题化知识库确认弹窗。两版共享本次功能与修复。

## 升级路径

RC7.9 → 0.1.2 正式版 → 开启预览更新 → 0.1.3 RC1.0。0.1.1.post4 用户也先升级 0.1.2。0.1.2 未开启预览时不会收到本版。

本预览采用 `yanami-sub-update-manifest-v2.json` 与 `.sig`，旧 RC7 更新器不会直接发现它；先安装 0.1.2 更新桥。清单签名内容格式与原信任公钥不变。采用完整更新包，同步启动器与应用。

用法见 `docs/knowledge-subtitle-import.md`。离线回归不消耗真实模型额度；真实蒸馏效果取决于模型和人工审阅，不是模型训练。
