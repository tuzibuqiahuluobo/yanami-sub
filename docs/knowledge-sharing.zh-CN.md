# 知识库共享：选一种方式

## 发给朋友：本地文件交换

1. 知识库 → 社区共享 → 本地文件交换，选择要发的条目，点击“导出 .md 文件”。保存为新文件名，再通过自己选择的方式发送。
2. 接收方先在“条目”页创建同名、同类别目标；已有该条目则直接选择它。
3. 点击“选择文件并预览”，打开 UTF-8 Markdown，核对全文与目标后点击“确认导入目标条目”。

不调用模型、不上传文件。导出包含所选条目正文，可能包含自己的笔记，请自行核对隐私；它不按“可共享”标记过滤。文件不包含数据库、密钥、任务、日志或历史，不是备份。导入使用核心人工编辑事务，会修订目标，可能移除未包含内容；旧版本仍在修订历史。文件一级标题须与目标同名，不接受任意网页/压缩包；一般文本请用“检查与恢复 → 从笔记或文档提取知识”，该操作可能调用模型。仅导入可信文件。

## 接收社区知识：无需填写服务器

点击“下载社区更新并合并”，确认后核心下载、验证并合并；不注册也能拉取。默认地址来自上游配置或内置社区。本地同一字段也有修改时，保留本地并记录冲突，去高级区域核对，不用清空知识库。

## 投稿：一次注册，逐条确认

首次投稿先注册；选择条目、标记可共享，再提交审核。只有已标记内容进入投稿，私有正文仍需自己核对。记下报告中的队列编号查询，提交成功不等于已经收录。注册凭据由核心保存，普通用户无需填写维护者令牌。

## 什么时候填写地址

只有别人向你提供另一个共享库时才展开“其他服务器”。填写完整 HTTPS 地址，HTTP 仅允许 localhost；不能填 GitHub 仓库页、Windows 文件夹或共享库编号。清空即恢复默认。换地址/换签名密钥可能触发上游安全确认，不会自动信任新身份。自建部署参见[上游自建指南](https://github.com/caca2331/finesub/blob/v0.7.0/docs/manual/share-server.md)。

网络失败先检查网络/代理或稍后重试，也可先本地交换；不要删除知识库或关闭签名校验。维护者审核、模型冲突修复是高级工作流，不属于下载或投稿的必经步骤，执行时可能调用当前模型并消耗额度。
