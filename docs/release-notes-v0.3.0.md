# Yanami Sub 0.3.0

核心升级为 FineSub v0.7.0，固定提交 7123055da0cd6e037d8e37feb53b82f9e428c5cb。

## 新能力

- 本地 MOSS、MOSS Pro、MAI2、Gemini Transcribe 一体转写；单任务与批处理共享选择，默认仍用本地 Whisper。
- 识别补漏、坍缩字幕修复与可选强制对齐；上游中文素材纠错/润色、流式重试、长素材与输出修复。
- 云端音频上传提示及加密凭据管理。MOSS Pro 超免费额度扣余额默认关闭，仅本次明确开启。
- 记住上次选项的设置开关，覆盖任务、批处理与知识库；不记忆任务正文、文件或一次性付费许可。

## 修复与界面

- 说话人模型与人数限制不再重叠；阶段换行设置固定间距。
- 移除“使用预设默认参数”复选框，切换预设不再覆盖知识库读写模式。
- 更易懂的预设、路由和错误说明；每个 Agent 独立配置弹窗，安装路径合并其中。
- 日志区分候选顺序与实际响应模型；纠错跳过时保留断点，不因原始字幕交付而清空 LLM 检查点。
- README 重写，补充引擎选择、隐私、费用和升级指南。

## 升级注意

完整更新会保留用户数据、任务与缓存，但新依赖锁要求首次准备运行环境。PSV 模型目录及已改名 target 可在设置中先预览、备份后转换；过期预览拒绝覆盖。已下线模型和显式环境变量路径冲突需要人工审阅。

API 代理不再支持 SOCKS，请使用代理软件的 HTTP 端口。旧未完成 LLM 任务的部分窗口可能需要重做；已完成的成品不因此修改。

本地 MOSS 要求受支持的 NVIDIA 显卡与至少 8 GB 显存。云端转写会上传音频并受账号额度/计费影响。CLI 就绪检测不等于登录、权限和额度验证。

0.3.0 面向正式通道；0.3.1 RC1.0 使用相同功能基线，供开启预览更新的用户使用。不覆盖或重新标记旧 Release。
