# Yanami Sub 0.3.1

Windows x64 正式版，核心为 FineSub 0.7.1。

- **字幕自动命名**：单任务、批处理的网络链接字幕默认使用视频标题。读不到标题时使用本地日期和时间，例如 `2026-11-23_10-30-05.srt`。手填名称不变，重名不覆盖已有字幕，已下载的媒体与任务断点不改名。「工具 → YouTube 字幕下载」的另存窗口也采用同一规则。
- **链接任务**：下载后继续走本地字幕流程。支持选择视频格式、画质和帧率；档位失效时提示重选或恢复自动，不会静默降低画质。
- **节目参考与分轨**：可添加节目片段及 SRT，按时、分、秒、帧对齐并预览。可按确认过的说话人分组导出，未确认的字幕保留在待确认文件。
- **字幕与核心工具**：可单独另存 YouTube 已有字幕为 SRT、VTT、TXT；合入 FineSub 0.7.1 的链接、Qwen、字幕兼容和转写改进，以及术语表、额度记录与 FineSub 专用 Codex 登录。

**升级**：0.3.0.post5 可直接完整更新到此版。也可退出应用后，用安装包覆盖安装到原目录；不需要先卸载或删除任务、模型、配置或知识库。
