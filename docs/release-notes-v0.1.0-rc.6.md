# Yanami Sub 0.1.0 RC6

RC6 是一次界面反馈与更新体验优化，版本串为 `0.1.0-rc.6`。字幕处理核心继续固定为
[FineSub v0.5.1](https://github.com/caca2331/finesub/tree/v0.5.1)。

## 本版更新

### 更轻、更统一的输入焦点

输入框、下拉框和知识库表单不再显示突兀的外层黑色双描边。键盘聚焦状态改为与当前主题色
一致的细边框和低透明度光晕，仍保持清晰可见，也不会影响键盘操作与无障碍识别。

### 新增右下角成功提示

显式完成的操作现在会显示与界面风格一致的右下角 Toast，包括：

- API Key、路由和共享字幕设置保存；
- 批处理清单导入、导出与队列完成；
- 资源下载完成、知识库维护与分享完成；
- 单任务完成和字幕导出。

Toast 不抢占焦点，最多同时显示三条，可手动关闭并会自动消失。错误仍留在原来的上下文位置，
避免把需要处理的问题误做成短暂提示。

### 更新下载改为全局圆形进度

应用内更新开始后，进度会固定显示在窗口右下角，并在切换页面后继续保留：

- 下载时显示圆形进度、百分比和已下载 / 总大小；
- 无法确定总大小或正在安装时显示环形活动状态；
- 下载完成后变为绿色勾选和“下载完成”，随后平滑收起；
- 设置页仍保留立即重启、退出后安装和重试等实际操作。

### 页面切换文字平滑衔接

主题色、新建任务 / 批处理阶段、知识库页签等共享选中背景的切换动画，现在会让旧文字淡出、
新文字淡入，避免选中项移动时文字瞬间消失。所有新动画都由“设置 → 外观 → 界面动画”统一
控制，并遵循 Windows 的“减少动态效果”偏好；首次安装仍默认开启界面动画。

## 安装与更新

- RC5 至 RC5.4：可在“设置 → 应用更新”中检查并安装 RC6；
- RC4 或旧版 FineSub Desktop：请手动运行
  `Yanami-Sub-0.1.0-rc.6-Setup.exe` 覆盖安装；
- 新安装：下载安装器及对应 `.sha256` 文件，校验一致后运行。

RC6 同时发布完整安装器、便携完整包、应用包、SHA-256 文件以及签名的在线更新清单。
安装包不做付费 Authenticode 证书签名；在线更新清单的项目签名只用于验证下载内容完整性。
