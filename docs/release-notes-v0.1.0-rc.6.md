# Yanami Sub 0.1.0 RC5.3

RC5.3 是 RC5 系列的缺陷修复版，处理核心仍固定为
[FineSub v0.5.1](https://github.com/caca2331/finesub/tree/v0.5.1)。版本串为 `0.1.0-rc.6`，
公开版本名为 RC5.3。

RC5、RC5.1 与 RC5.2 的版本串都落在 `rc.5` 上（`rc.5` / `rc.5.post1` / `rc.5.post2`），
本次起进入 `rc.6`。`rc.5.3` 不是合法的 Python 版本串，无法用于安装包与在线更新比较。

## 本版更新

### 修复：Python 运行环境装不上（`os error 448`）

首次准备运行环境时，若程序没能在本机找到可用的 CPython 3.12，会退到
`uv python install` 去下载一份私有 Python。该路径需要在 Windows 上创建 junction
（次版本号链接目录），在部分用户配置目录下会被拒绝，报
`Failed to create Python minor version link directory ... (os error 448)`。此时“继续下载”
每次都会走同一条路，表现为卡住。

本版不再依赖该路径：

- **补齐解释器发现**。除 `python3.12` / `python` 与 `py` 启动器外，也读取 `py -0p`
  注册的解释器（**包括安装时没有勾选“Add to PATH”的**）以及常见安装位置；找到现成的
  3.12 就用它创建运行环境，只下载 AI 依赖。
- **修正版本判据**。旧判据比较的是完整版本元组，解释器输出多一个字符就会被判成
  “没有 Python”而静默跳过。
- **可以手动指定**。资源页「运行诊断 → Python 解释器」新增“指定解释器”，可直接选择
  一个 `python.exe`；保存后重启应用生效。该区块同时列出**每一个被检查过的候选以及被
  拒绝的原因**（版本不符 / 不是解释器 / 路径不存在），因此“我明明装了 Python”可以直接
  看出是哪一个被拒。

### 修复：应用启动后停在模糊页面上，看起来像卡死

点「开始生成」后确认弹窗渲染在**视口之外**：屏幕上只剩一个被模糊、点不动的页面，向上
滚动才看得到弹窗。成因不在弹窗本身——工作区容器上带着一个 `fill-mode: both` 的入场动画，
其 `to` 帧的 `transform` 会**永久生效**，使它成为 containing block，`position: fixed` 的
弹窗因此按滚动面板而非视口定位。已改为只过渡 `opacity`，并同时锁住背景滚动。

### 修复：诊断结果把可选项说成阻断项

「运行诊断」此前把 `yt-dlp`、本地分词器与 Python 运行环境一并标红，标题写“会阻止任务
运行的问题”，但前两者是可选的（本地文件任务不需要 yt-dlp，分词器缺失会回退在线计数）。
现在三态显示：可用 / 阻断（红）/ 可选（琥珀）。

### 修复：诊断里的「模型目录」不是实际读写位置

Hugging Face 与分离器在通用缓存（`~\.cache\huggingface`、`~\.cache\audio-separator`）
已有文件时会改用那里，此时安装目录下的 `models` 根本不存在，界面却同时显示该路径并报
“模型权重已就绪”。诊断现在并列显示**实际生效**的位置，避免“迁移大文件目录”和
“清理可重建数据”作用到一个空目录。

### 修复：从外部写入的 `.env` 需要重启应用才生效

与 FineSub CLI 共用数据目录时，从别处拷入或由 CLI 写入的 API Key 现在会在窗口重新获得
焦点时重新读取，不再需要重启。通过界面保存 Key 的路径不受影响。

### 修复：任务页承诺的模型下载量与资源页矛盾

「模型权重按需下载（合计约 3.4 GB）」是写死文案，而资源页可能同时显示“已就绪”。该提示
现在跟随后端真实状态；模型已在本机时不再承诺下载。

### 改进：「输出结果」增加翻译字幕一档

下拉框此前只有「原始字幕」和「最终字幕」，无法停在两者之间。新增
`翻译字幕（LLM 处理后，不做后处理重排）`，对应上游的 `translated-srt` 阶段——需要
“纠错/翻译但不要重新断句”时选它，其产物也会正常发布到源媒体旁。

### 修复：任务完成后点侧栏「新建任务」没有反应

完成卡片此前被钉在路由之外，侧栏与卡片内两个同名入口行为不一致。现在侧栏即可回到表单。

## 安装与更新

- 已安装 RC5.2：可在“应用更新”中检查并安装 RC5.3，也可以手动运行安装器；
- 已安装 RC5 / RC5.1：可手动运行 `Yanami-Sub-0.1.0-rc.6-Setup.exe` 覆盖安装；
- 已安装 RC4 或更早的 FineSub Desktop：必须先手动运行上述安装器覆盖安装一次；
- 新安装：同时下载安装器及其 `.sha256` 文件，校验一致后运行。

## 校验与许可

安装包、应用归档和完整归档均附带 SHA-256 校验文件。Yanami Sub 遵循上游当前的
`GPL-3.0-or-later`；详细作者、迁移来源与 prompt 模板许可见 [NOTICE](../NOTICE.md)。
