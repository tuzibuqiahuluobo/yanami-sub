# Yanami Sub 0.3.1 RC1.6

此版本是 Windows x64 **预览版**，FineSub 核心仍为 0.7.0。

- 新建本地视频任务可添加节目短片和 SRT。输入两段视频中的对应时间和连续播放长度，可添加多段处理暂停、回放和跳播。预览抽样后明确启用。
- 节目短片只在本机检查，匹配的字幕文字只在对应纠错窗口作为语境参考；不会自动把节目字幕覆盖到主播字幕上，也不会做原声抵消。请勿使用不宜发送给所选模型的字幕。
- 开启说话人分离并完成翻译后，可以按轨号手动分组，另存主播、节目和待确认译文。重叠、低置信度和未确认的句子不会被丢弃，完整字幕不变。原始分轨折叠显示。

**更新方式：**接收预览更新的用户用应用内完整更新，或退出应用后用本页安装器覆盖原目录。运行环境、模型、任务、设置和知识库无需先删除。正式版仍为 0.3.0.post5。

**验证范围：**自动测试覆盖字幕编码、时间轴裁切/回放、越界、窗口隔离、重试和分组完整性。对齐与分组不需要调用模型。尚未使用长视频或在线付费模型评估翻译质量提升。
