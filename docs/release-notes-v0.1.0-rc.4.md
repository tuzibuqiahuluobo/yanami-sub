# Yanami Sub 0.1.0 RC4

RC4 集中修复 RC3 沙箱验收中确认的配置提示、状态刷新和错误展示问题，处理核心仍固定为
[FineSub v0.5.1](https://github.com/caca2331/finesub/tree/v0.5.1)。

## 本版更新

- 在任务启动前校验联网检索与实际模型路由；免费模型不支持原生搜索时直接给出可操作提示，
  同时正确识别单任务模型覆盖；
- 自动同步任务历史，通过 API 启动或由其他入口写入的任务无需刷新页面即可出现；
- 资源页面持续读取后端真实状态，下载完成后立即更新“已就绪”结果；
- 任务卡片使用简洁错误摘要，完整异常仍保留在日志与悬浮提示中；
- 将已知的 AOTI / Triton 显存回退噪声只写入文件日志，避免干扰界面中的关键进度；
- 清理桌面端残留的旧 FineSub 产品文案，同时保留必要的上游核心名称和共享数据兼容路径；
- 当快速模式会让 `research=` 路由覆盖不参与首轮处理时，在高级设置中给出明确提示；
- 包含 RC3 安装目录修复，新安装默认使用 `%LOCALAPPDATA%\Programs\Yanami Sub`。

## 安装与更新

- 已安装 RC3：可以在 Yanami Sub 中检查更新，也可以下载 RC4 安装器覆盖安装；
- FineSub Desktop 旧版：请先退出主窗口和托盘进程，再手动运行 RC4 安装器迁移；
- 新安装：下载 `Yanami-Sub-0.1.0-rc.4-Setup.exe` 及其 `.sha256` 文件，校验一致后运行。

## 预览版说明

- 本版为 prerelease；建议先备份 `%LOCALAPPDATA%\FineSub\user-data` 中的重要设置与知识库；
- 当前构建环境没有受信任的 Authenticode 证书，因此安装包与可执行文件未做可信代码签名；
- 应用内更新清单仍使用内置 Ed25519 密钥签名，并附带各发行文件的 SHA-256 校验值。
