# Yanami Sub 0.2.1

正式版。相比 0.1.2，字幕核心升级并固定为 FineSub v0.6.0（`5caf422cbad36f0402c98eb565e4c29aee4ac197`），不追随上游 main 自动变化。

## 更新内容

- 完成单任务、批处理、历史任务、设置与知识库工作流的 0.6.0 接口适配。保留历史记录；已失效的模型路线在再次执行前明确提示重选，不静默换用其他模型或付费服务。
- 原 WorkBuddy 桌面内置通道改为上游独立 CodeBuddy CLI；支持官方 npm 安装入口与自选路径，旧桌面登录凭据不复用。需要使用该通道的用户请重新安装、登录和选择模型；CLI 检测成功不代表登录、模型授权或额度已验证。
- 知识库需要升级时，先在写锁保护下备份并校验数据库、原始条目、配置与待应用提案，再交由核心迁移。备份失败不升级；不自动覆盖恢复，不提供一键降级。
- 精修回灌完整继承风格与材料证据，生成和提交同一份冻结提案；知识库冲突、部分成功、仅记录证据和无变化分别提示。保留中间清理后的风格选择回执。
- 设置增加旧媒体配置的检查与确认转换；无法可靠转换的自定义模型绑定不会猜测改写。运行环境核对、修复策略和活动任务租约共用核心接口，失败后只检查，不自动重跑任务。
- 修复依赖修复参数未转发，以及重试丢失输出归属导致重复生成字幕文件的问题；保留用户编辑字幕的保护。
- 修复 Hugging Face 下载端点回退时 Xet 策略不匹配，以及中文 Windows 下可选编译器诊断输出的解码失败；单任务与批处理一致。

## 升级说明

- 0.1.2 正式版可直接应用内升级至 0.2.1。0.1.3 RC1.0 等较旧预览版也可升级至本正式版。采用完整更新包，同步启动器与应用；可信签名公钥不变。
- 正式版默认仅接收正式更新；主动开启“接收预览版本更新”后，可获取 0.2.2 RC1.0（规范标签 `v0.2.2-rc.1`）。
- 核心依赖组合已变化，首次任务前可能需要重建受管 Python 环境并下载依赖。保留原模型缓存、任务和设置；请预留下载时间与磁盘空间。
- 升级前建议自行备份知识库与自定义配置。自动迁移备份不是整个应用的一键回滚；请勿在应用运行时手动覆盖数据库。新核心产生的数据不保证能由旧版直接读取。
- 无法启动或无法应用内更新时，退出应用后用本版 Setup 选择原目录覆盖安装，无须先卸载或删除任务、模型。

## 验证与已知限制

- 已完成隔离托管环境安装、真实 GPU 原始字幕全流程、中日文路径与输出编码检查，以及后端、前端和打包回归；真实测试未调用 API 或 Agent，不保证供应商账号、额度或翻译质量。
- 完整可选 AOTI 加速仍有 CUDA 加载异常；编译失败时沿用 eager CUDA，并不表示 GPU 识别不可用。本版不承诺所有显卡的编译加速或固定提速比例。
- 镜像可能缺少 Hugging Face 校验元数据，应用仍拒绝不完整来源并尝试官方源；全新大权重在线下载受网络影响，尚未完整验收。
- 云端构建不等于已在所有用户机器验收安装、升级、卸载和恢复；运行环境和账号差异仍可能需要诊断。安装器未配置 Windows Authenticode 发布者证书；在线更新清单使用既有 Ed25519 密钥签名。

详细兼容和验收边界见 [迁移记录](https://github.com/tuzibuqiahuluobo/yanami-sub/blob/v0.2.1/docs/core-060-migration.md)。
