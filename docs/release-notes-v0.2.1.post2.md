# Yanami Sub 0.2.1.post2

资源引导与界面反馈修复。FineSub 核心保持 v0.6.0（`5caf422cbad36f0402c98eb565e4c29aee4ac197`），不修改识别算法。

## 更新内容

- 修复首页所需组件下载时右侧按钮仍显示下载图标的问题；排队、下载进度、暂停和失败重试随实际状态更新。
- 新建任务、批处理开始、恢复或运行中追加时，如果缺少资源或配置，会说明原因并前往相应位置。链接任务缺少 yt-dlp 时定位到该组件；必需资源持续黄色标记，下载完成后解除。
- 从引导页面返回时保留任务文件、批处理链接和参数；处理完条件后由用户主动继续，不自动重复提交。
- 改进公共确认弹窗、下拉框、折叠区域和通知的交互，尊重应用与系统的减少动态效果设置。

## 升级

- 正式版默认接收本补丁；预览版用户可升级到对应的 `0.2.2-rc.1.post2`。正式版不会自动接收预览，除非主动开启预览更新。
- 由于修改了原生桥接响应，应用内更新使用完整更新包；保留运行环境、模型缓存、设置和任务。在线更新使用原有 Ed25519 密钥签名。
- 如果应用内更新失败，退出应用后可使用 Setup 安装到原目录覆盖更新，不需要先卸载或删除模型。

## 验证与限制

- 完成前后端与打包回归；隔离环境实际下载并校验 yt-dlp，验证了缺失资源提示及跨页返回。
- 未取得原用户批处理故障的具体错误日志，不能断言其唯一原因。未使用真实模型或账号重跑完整字幕任务，也未对所有独立定制弹窗统一退场动画。
- 安装器未配置 Windows Authenticode 发布者证书。
