# Yanami Sub 0.1.0 RC6.2

RC6.2 重点修复 Python 与 AI 依赖下载线路误判后无法纠正的问题，内部版本串为
`0.1.0-rc.6.post2`。字幕处理核心继续固定为
[FineSub v0.5.1](https://github.com/caca2331/finesub/tree/v0.5.1)。

## 本版更新

### 下载线路可以查看并手动切换

- “资源”页面新增“自动选择 / 国内镜像 / 官方源”三种下载线路；
- 界面会显示当前实际生效的线路，而不只显示偏好设置；
- 国内镜像使用清华大学 TUNA PyPI 与上海交通大学 PyTorch 镜像；
- 线路偏好会保存在本机，并在下一次 Python 运行环境下载时生效。

### 自动检测与失败恢复更可靠

- 重新选择“自动”会立即探测网络，不再只能沿用旧的 24 小时缓存；
- 用户明确选择国内镜像时，会重新启用曾因临时网络错误降级的镜像线路；
- Python 运行环境正在下载时会要求先暂停再切换，避免同一次安装混用两条线路；
- 切换成功后通过右下角 Toast 明确提示，不需要猜测设置是否已经保存。

这次改动解决的是单个大型 PyTorch wheel 因线路选择不合适而长时间下载的问题。`uv` 仍会
并行下载不同依赖；单个 wheel 的分片下载不在本补丁范围内。

## 安装与更新

- RC5 至 RC6.1：可在“设置 → 应用更新”中检查并安装 RC6.2；
- RC4 或旧版 FineSub Desktop：请手动运行
  `Yanami-Sub-0.1.0-rc.6.post2-Setup.exe` 覆盖安装；
- 新安装：下载安装器及对应 `.sha256` 文件，校验一致后运行。

RC6.2 同时发布完整安装器、便携完整包、应用包、SHA-256 文件以及签名的在线更新清单。
安装包不做付费 Authenticode 证书签名；在线更新清单的项目签名只用于验证下载内容完整性。
