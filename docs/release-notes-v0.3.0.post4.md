# Yanami Sub 0.3.0.post4

## 修复与改进

- 下拉菜单使用浏览器顶层显示，修复被后方卡片遮挡及点击误落到其他选择栏；保留圆角、滚动、键盘和视口上下自适应。
- 社区共享不再强制填写地址，默认使用上游配置/内置社区；已注册列表恢复正确 URL，而不是共享库编号。
- 本地知识条目可导出 UTF-8 Markdown，并选择文件、全文预览和确认导入；复用核心人工编辑事务，不调用模型、不上传，不是完整备份。
- 共享页面区分本地/联网，显示使用步骤和隐私边界；高级服务器、冲突和维护者操作折叠收起，投稿和合并前确认。
- 更新 README、共享指南与视频封装/压制风险评估；本次没有新增视频压制功能。

固定 FineSub v0.7.0，保留 post3 Qwen 注意力兼容。启动器增加原生文件对话框，采用完整更新包；保留任务、知识库、配置与模型，不需要先卸载。

## 验证与限制

相关后端与前端回归通过，检查菜单跨卡片点击、键盘、滚动、深浅色与响应式布局；本地 Markdown 经核心读写和历史回读验证。默认社区公开身份、快照完整性和内置公钥签名通过只读在线检查；没有实际注册、投稿或修改用户知识库。服务可用性和审核时间由上游社区决定。

本地导入可能移除目标中未包含的正文，需预览确认；仅导入可信条目，导出前检查隐私。安装器未有 Windows Authenticode 发布者证书签名；应用内更新使用原有 Ed25519 清单签名。没有运行本轮原地覆盖安装或完整长视频任务。
