# Yanami Sub 0.1.0 RC5

RC5 合并 RC4 之后确认的更新、卸载、首次启动与知识库界面修复，处理核心仍固定为
[FineSub v0.5.1](https://github.com/caca2331/finesub/tree/v0.5.1)。

## 本版更新

- 修复应用更新完成后“立即重启”无反应：新程序启动成功后才关闭当前窗口；
- 卸载前自动强制关闭 Yanami Sub 及其工作进程，避免文件占用导致卸载失败；
- 首次安装默认使用浅色主题，已有用户保存的主题选择保持不变；
- 系统已经存在 Python 时不再误报“请先安装 Python”，改为提示仍缺少的 FineSub AI 依赖；
- “正在读取知识库”只在真实读取进行中显示，失败或结束后不会残留假加载状态；
- 修复知识库维护页在中等窗口宽度下按钮越界、遮挡的问题；
- 完整更新器开始保留 Inno Setup 卸载器，为后续版本安全恢复应用内更新做准备。

## 安装与更新

- 已安装 RC4：请下载并运行 `Yanami-Sub-0.1.0-rc.5-Setup.exe` 覆盖安装；
- FineSub Desktop 旧版：请先退出主窗口和托盘进程，再手动运行 RC5 安装器迁移；
- 新安装：同时下载安装器及其 `.sha256` 文件，校验一致后运行。

RC5 不发布在线更新清单。原因是执行完整更新的是已经安装的 RC4 更新器，而 RC4 会移除
Inno Setup 卸载器，导致 Windows 卸载项失效；这项旧版行为无法由下载后的 RC5 文件补救。
RC5 安装器会刷新卸载器并安装已修复的更新器。

## 预览版与签名说明

- 本版为 prerelease；建议先备份 `%LOCALAPPDATA%\FineSub\user-data` 中的重要设置与知识库；
- 当前构建环境没有受信任的 Authenticode 证书，因此安装包与可执行文件未做可信代码签名；
- 安装包、应用归档和完整归档均附带 SHA-256 校验文件；更新清单只在本地构建验证，不作为
  RC5 Release 资产发布。
