## 2026-09-23 implementation decision

- Keep FineSub v0.5.1 locks and SHA-256 unchanged. Override only the desktop-managed uv bootstrap to the verified official 0.12.17 Windows x64 archive; the upgrade adds upstream in-process HTTP Range retry for wheel transfers.
- Add bounded recovery on actual network failures: first transport proxy to direct, then automatic source fallback from official to the existing China mirror lock (the core already handles China mirror to official). The desktop creates a temporary byte-identical `pylock.win-py312-cn.toml` (also for verified local URL substitutions); both official and normalized mirror locks passed an actual uv 0.12.17 offline dry-run without downloading dependencies.
- Auto mode now samples at most 256 KiB from each pinned PyTorch source and, before preferring the China lock, also samples one TUNA PyPI wheel host. A clear (>1.5×) short-sample advantage can change initial source priority; ambiguity/probe failures retain the existing regional decision. This is a bounded heuristic, not a sustained-throughput guarantee, and user-forced source modes bypass it.
- The desktop uv override applies only while FineSub's own manifest still names 0.11.32. A future upstream bump is not overwritten. Because this adapter is in the frozen launcher, existing installed clients need a full installer/update payload (not an app-only patch) to receive it.

# Subtitle-processing log encoding investigation (2026-09-24)

- FineSub upstream main/latest release remain v0.5.1 at `b9b2f10c80abd58ddff739b60461624f51c0789c`; no upstream merge planned. Prior HF-warning edits are still uncommitted and must be preserved.
