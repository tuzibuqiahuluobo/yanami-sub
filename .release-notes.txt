## 改进

### Agent 健康检查与预检测机制

- **新增**：任务开始前预检测 Agent 可用性，避免浪费 ASR 处理时间
- **新增**：详细的 Agent 健康检查，识别配额不足、提供商禁用、认证失败等问题
- **改进**：清晰的错误分类和诊断信息
- **改进**：为每种错误类型提供可操作的解决建议
- **优化**：从失败后报错改为提前检测，节省 5-10 分钟的等待时间

### 错误提示优化

- **改进**：Agent 失败时显示具体原因（quota、provider_disabled、auth_failed 等）
- **改进**：增强错误消息，包含详细的诊断信息和解决建议
- **改进**：记录每个 Agent 的健康状态到任务日志

### 用户体验提升

- **优化**：立即发现配置问题，不再在 ASR 完成后才报错
- **优化**：清晰告知用户应该如何解决问题（充值配额、检查配置等）
- **优化**：部分 Agent 可用时继续任务，只警告不可用的 Agent

## 技术细节

- 新增 `agent_health_check.py` 模块，提供轻量级健康检查（< 10秒）
- 集成到任务执行流程，在 ASR 阶段之前进行预检测
- 增强日志记录，包含详细的路由选择和 Agent 状态信息
- 完整的单元测试覆盖
