# FineSub 0.7.0 更新与桌面端合并计划

日期：2026-11-10。目标版本：正式版 0.3.0 / 预览版 0.3.1 RC1.0。
上游固定为 [v0.7.0](https://github.com/caca2331/finesub/releases/tag/v0.7.0)，提交 7123055da0cd6e037d8e37feb53b82f9e428c5cb，不追随浮动 main。

## 上游更新分析

- 一体转写：可选本地 MOSS、云端 MOSS Pro、MAI2、Gemini Transcribe；转写、说话人和时间轴一次生成，保留原始回答缓存以续跑。桌面端默认仍用本地 Whisper；云端须明确选择并说明上传、额度与费用。
- 中文素材只纠错与基础润色、不再翻译；普通话识别统一简体。由核心判断素材语言，不能由界面自行猜测。
- 中档成为默认，高档额外启用说话人裁判、多 pass 与校对，速度/费用增加；快速预设使用纯文本。界面必须表达这些差异。
- 识别补漏、坍缩行修复与说话人拆行，纠错错位检测、增量修复与拼接防丢行，长片分块准备与名称一致性。
- API 流式接收与网络重试、离线 tokcount、不可达告警、残缺回答保留；使用核心的可靠性机制，删除已重复或不兼容的桌面兼容处理。
- catalog 改 TOML、按键覆盖、能力改四档且仅作提示；target 合并改名，部分模型下线；旧配置必须预览、备份后迁移，不偷偷切到付费模型。
- 批处理状态、并发写入、续跑日志及字幕输出修复；安全修复包括路径约束、检索内容边界、代理凭据脱敏和 Agent 隔离。
- 首次运行按新依赖锁重建环境；未完成的旧 LLM 窗口可能重做，完成的成品不应修改。

## 实施步骤与验收门槛

1. 核心契约：固定 source pin、依赖和运行环境清单；核对 API/批处理/知识库接口。旧格式 catalog、target、超时和代理设置提供可审阅转换；保存原文备份且预览过期不覆盖。
2. 任务入口：单任务与批处理共享识别后端、修复参数和校验；提供必要凭据与隐私提示，保留本地默认，云端付费不自动开启。
3. 合入 [九项需求](2026-11-10-ui-task-requirements.md)：布局、冗余勾选、文案、持久化开关、错误分类、实际模型日志和逐 Agent 配置。
4. 验证：后端/打包测试、前端测试/类型检查/静态构建、不同窗口与主题的界面回归；真实 GPU 与付费云端结果须分别标明实测状态，不能用 mock 冒充。
5. README 与版本说明：说明新能力、兼容迁移、费用隐私、断点限制和更新方式；双通道各自构建、验签、核对版本与哈希再发布，不覆盖旧标签。

未满足兼容性或验证门槛前不发布。
