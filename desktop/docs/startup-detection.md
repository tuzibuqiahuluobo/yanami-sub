# 启动检测与黑色命令行窗口

Windows 安装版先显示原生启动小窗：检查安装文件 → 准备运行环境 →
逐个检查本地 Agent → 关闭小窗并显示主界面。复用既有 WinForms/pythonnet，
不额外启动浏览器，也不提前导入尚未完成完整性检查/健康回滚的应用核心。

Agent 检测仅运行官方 CLI 的版本/帮助/本地能力命令，不请求模型，不验证或消耗账号额度。
探测子进程使用 `CREATE_NO_WINDOW`、关闭标准输入；每个子命令最多 15 秒，
整轮 CLI 能力检测预算 60 秒（不含安装校验、路径发现或主页面加载）。
超时或不可用显示在就绪检测结果中，主界面仍能打开。
单实例保护覆盖整个检测过程；关闭小窗取消启动，在当前有界探测结束后释放所有权。

同时发出的检测请求合并为一次；进入主界面时复用启动检测结果，不自动重复扫描。
设置页稍后点击“开始检测”仍会重新扫描。主动打开 WorkBuddy 登录桌面等交互界面不受隐藏控制台适配影响。

`session-*.log` 记录每个检测项、结果和耗时（不写凭据），用于区分黑窗闪烁、CLI 等待与真正的启动崩溃。
日志仍可从设置底部打开。
